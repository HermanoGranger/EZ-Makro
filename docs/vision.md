# EZ Makro — Vision

## Produktvision

EZ Makro ist eine offline-first Android-App, mit der Nutzer:innen Kalorien,
Makros und Rezepte tracken — schnell, privat und ohne Ablenkung.

Die App soll das tägliche Tracking so reibungslos wie möglich machen:
Lebensmittel per Barcode scannen, eigene Rezepte aus Rohzutaten berechnen,
Tagesziele im Blick behalten. Kein Login, keine Cloud, keine Werbung, keine
künstliche Gamification. Die Daten gehören allein dem Nutzer.

## Kernwerte

- **Privatsphäre zuerst:** Alle Daten bleiben lokal auf dem Gerät. Es gibt
  kein Backend, keine Accounts, kein Tracking.
- **Offline-First:** Die App funktioniert vollständig ohne Netzverbindung.
  OpenFoodFacts ist eine optionale, ergänzende Datenquelle, niemals zwingend.
- **Einfachheit:** Jede Interaktion ist in wenigen Taps erledigt. Komplexität
  nur dort, wo sie Ernährungsgenauigkeit wirklich braucht (z. B. Roh-/Endgewicht).
- **Transparenz:** Berechnungen sind nachvollziehbar. Was die App anzeigt,
  lässt sich auf die eingegebenen Rohdaten zurückführen.

## Erfolgskriterien (für Phase 0)

- Architektur, Module und zentrale Domänenregeln sind festgelegt und
  dokumentiert.
- Keine offenen Kernentscheidungen mehr vor Beginn der Implementierung.
